# 源码包（Stronghold-Protocol-Forge-0.18.3-0.18.3-src.zip）

本包是《卫戍协议：Forge》**0.18.3** 的源码，内容 = 版本库的跟踪文件
（`git ls-files` 的 **1787** 个），**不含**：

- 美术素材（`public/assets/**`、`public/fonts/`，都是 .gitignore 的）
- 本地客户端提取清单 `data/local-assets.json`
- 运行依赖 `node_modules/`、`public/vendor/`（`npm ci` 生成）
- 内容包索引 `packs/index.json`（构建产物）

## 跑起来

```
npm ci
npm run setup     # 首次运行会下载素材；官方 3D 棋盘与本机客户端素材需自行从《明日方舟》提取
npm start         # http://127.0.0.1:3000
npm test          # 全量测试（本包带了 test/）
```

没有素材也能玩：棋盘退回 2D 程序化版本。
顺手可跑 `npm run doctor` 看设备就绪情况。

## 版本

- 本仓库版本：`0.18.3`
- 上游游戏本体底座：**v0.2.6**（tag `v0.2.6` = commit `488db49`）
- 本包**不含** `MANIFEST.json` —— 那是 `npm ci` 之后写出的安装校验清单
  （`server/update.js` / `npm run doctor` 用），源码目录没有安装步骤，不做该校验。
