# 卫戍协议：盟约 · Windows 开箱即用整合包

《明日方舟》同人复刻「卫戍协议：盟约」（Stronghold Protocol: Alliance）的**零安装整合包**：解压后双击即开服 —— 游戏本体、全部美术与音频素材、两个社区工坊 mod、便携版 Node 都在包里。

## 这是什么

「卫戍协议：盟约」是自走棋 + 塔防：休整期在调度中心招募干员、摆阵、配装备，作战期干员自动部署，迎击从红门涌来的敌人，漏过去的敌人扣目标生命值。本项目在浏览器里复刻了这一玩法，规则与数值尽量对照官方数据表与 PRTS 核对。

本整合包把「开箱即玩」需要的全部东西打进一个目录：

| 组成 | 位置 | 说明 |
|---|---|---|
| **游戏本体** | `app\` | 服务器（Node）+ 浏览器客户端；战斗在各玩家浏览器里模拟，服务器只管经济与回合 |
| **工坊编辑器** | `启动编辑器.bat` | 图形化创作工具，改干员 / 地图 / 怪物 / 出怪 / 装备 / kit / 语音 |
| **社区工坊 mod** | `app\workshop\` | 颂乐人偶、雷姆必拓两个数据包（见 [内置工坊包](#内置工坊包)） |
| **便携版 Node** | `node\` | 官方 x64 Node v22.23.3，已 sha256 校验；目标机不必另装 |

- **独立模拟**（单人）与**同盟模拟**（1–4 人**合作**，没有 PvP；空位可以加 AI 队友）。
- **不联网也能玩**：美术 / 音频 / 依赖 / 字体全部在包内。联网时页面还会去 Google Fonts 加载 Noto Sans SC 这类网页字体，只为让中文更接近原版观感 —— 断网不会卡住或报错。

## 快速开始

解压后双击即可，**不需要先下载素材、也不需要装 Node**：

```
启动游戏.bat      在这台电脑开服，浏览器自动打开（本机当服务器）
启动编辑器.bat    打开工坊编辑器（127.0.0.1:3311）
安装工坊包.bat    拿到别人做的工坊包 .zip，拖到它上面松开即装好
```

Linux 服务器可用仓库根目录的 [`start.sh`](start.sh)：它从本仓库克隆完整包并启动（已内置镜像回退与重试，适合网络不稳的连接）。

编辑器默认**只绑本机**（它可以写文件，没有登录与权限控制），端口 3311；换端口：`启动编辑器.bat --port 3400`。
编辑器只写 `app\workshop\**` 与 `app\data\support.json`（仅在你动「是否助战」开关时），`tools\build-data.mjs` 生成的其它 `data\*.json` 永不改动。
**保存后需重启游戏服务器**才会出现在游戏里。

## 怎么玩

```
本机当服务器   双击 启动游戏.bat：在这台电脑开服，浏览器自动打开；
               控制台会打印「发给朋友」的局域网地址（形如 http://192.168.1.23:3000）
连别人的服务器 不需要这个包，直接用浏览器打开对方的网址就行
```

第一次开服时 Windows 防火墙可能弹窗，勾选**允许专用网络**（否则朋友连不上）。
建房后把 4 位「同盟密钥」或「复制链接」（`…/?room=密钥`）发给朋友即可。

## 内置工坊包

两个包都放在 `app\workshop\` 下，走创意工坊**叠加层**加载，官方 `data\*.json` 保持字节不变。可以用编辑器直接改，也可以导出成 `.zip` 分享给别人的 `安装工坊包.bat`。

| 工坊包 | 版本 | 内容 | 语音 | 模型 |
|---|---|---|---|---|
| **颂乐人偶**（`ave-mujica`） | 1.0.0 | 5 名成员干员（丰川祥子 / 三角初华 / 祐天寺若麦 / 八幡海铃 / 若叶睦）、成员特质、5 层人数盟约 | 日文（5 人） | 5 人全套官方 Spine |
| **雷姆必拓**（`rimbilliton`） | 1.1.0 | 9 名卡池干员、核心盟约「开拓心」、特质 / 装备 / 开拓大地策略 / 沙地兽 token | 日文 · 中文 · 英文 · 韩文 | — |

- 两个包**互相兼容**：若叶睦同时属于两个盟约。
- 干员语音走工坊包自己的 `assets\voice\`，客户端**零改动**即可听到（叠加层把台词并进它本来就在读的语音表）。

## 语音与语言

- **默认配音是日文**（jp）。音量在 **设置 → 干员语音（VOICE）**，默认 `0.8` —— 音效与语音是两条独立通道，调一个不影响另一个。
- 干员语音分**行动出发 / 行动开始 / 选中 / 部署 / 作战中 1-4**，以及结算时各自队伍 MVP 的那一句。
- **设置 → 配音语言** 选全局默认；任何干员的 **干员详情 → 配音** 还能单独换。选了没装的配音时会自动退回默认配音那一句，设置里也会标明哪几种没装。
- 本包**只内置日文配音**（`app\public\assets\audio\voice\`）；中文 / 英文 / 韩文配音不随包提供。
- 两个 mod 自带语音：**颂乐人偶**为日文，**雷姆必拓**为日文 / 中文 / 英文 / 韩文；装包后即生效。

## 目录结构

```
node\node.exe            便携版 Node v22.23.3（官方 x64，已 sha256 校验）
node\LICENSE-node.txt    Node 自己的许可证（MIT）
app\                     游戏本体：server / shared / public（全部素材）/ data / editor / scripts / tools
app\workshop\            内置工坊 mod：ave-mujica（颂乐人偶）、rimbilliton（雷姆必拓）
启动游戏.bat             app\scripts\launch.mjs --no-setup（开服，浏览器自动打开）
启动编辑器.bat           app\tools\workshop-editor.mjs --open（工坊编辑器，127.0.0.1:3311）
安装工坊包.bat           把一个工坊包 .zip 拖到这个文件上即装好
start.sh                 Linux 服务器一键拉取并启动
README.md                本文件
LICENSE / NOTICE.md / THIRD-PARTY-NOTICES.md
```

卸载 ＝ 直接删掉整个文件夹（不写注册表、不放系统目录）。存档 / 昵称在该电脑的浏览器 localStorage 里。
